Launchpad musical — 3 octavas

36 pads cromáticos con sonido integrado. No necesitas un sintetizador externo.

Toca o mantén pulsado un pad para sonar. Activa «Mantener nota al tocar» para alternar cada nota con un toque. También funciona con el teclado: Z S X D C V G B H N J M para la primera octava.
